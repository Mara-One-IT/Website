Frequently Asked Questions

Direct answers about Mara One IT's crypto trading bot, blockchain, and exchange infrastructure services.

What does Mara One IT do?

Mara One IT builds and operates infrastructure for automated crypto trading, blockchain node and network support, and exchange platform deployment. It helps traders, funds, and businesses run reliable, secure, production-grade crypto systems.

What is a crypto trading bot, and how does Mara One IT deploy one?

A crypto trading bot is software that executes trading strategies automatically by connecting to exchange APIs. Mara One IT sets up and deploys custom trading bots using Hummingbot and similar frameworks, configuring strategies, connecting them to one or more exchanges, and setting up monitoring dashboards and secure API credentials.

Which exchanges does Mara One IT support?

Mara One IT provides multi-exchange connectivity, including Coinbase Advanced Trade, Kraken, and Bitstamp, and more. For exchanges or trading pairs that aren't natively supported, Mara One IT builds custom exchange and candle-feed connectors.

What is Hummingbot?

Hummingbot is an open-source framework for building and running automated crypto trading strategies, such as market making and arbitrage. Mara One IT specializes in configuring, deploying, and operating Hummingbot (and similar frameworks) in production. Learn more on the Trading Bot Solutions page.

Does Mara One IT provide blockchain infrastructure services?

Yes. Mara One IT deploys and maintains blockchain nodes, sets up wallet and network infrastructure, and integrates blockchain connectivity into trading and exchange systems. See Blockchain Infrastructure for details.

How does Mara One IT secure exchange platform servers?

Exchange platforms are deployed with Docker and nginx, secured with SSL/TLS via Certbot, connected privately across servers using Tailscale, hardened with UFW firewall rules, and kept running in production using systemd service management. Full details are on the Exchange Deployment page.

What is Tailscale used for at Mara One IT?

Tailscale is used to build a secure private mesh network between servers, so internal services such as admin interfaces and databases don't need to be exposed on the public internet.

Is Mara One IT based in the United States?

Yes, Mara One IT is based in the USA. Operating from the United States supports regulatory and client trust alignment for clients working within US business norms.
