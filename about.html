How the stack fits together

A typical production deployment runs on Ubuntu/Linux servers, with individual services — trading bots, exchange components, dashboards — containerized using Docker and Docker Compose for reproducibility. nginx handles reverse-proxying and routing, with Certbot managing SSL/TLS certificates so traffic is encrypted. Tailscale connects multiple servers into a private mesh network so internal traffic never has to touch the public internet, while UFW restricts what is exposed publicly in the first place. systemd keeps every service running, restarting automatically on failure to support production uptime.
